# Cybersecurity Labs

This repository contains hands-on cybersecurity exercises focused on real-world scenarios such as network analysis, incident response, and vulnerability assessment.

## Skills Demonstrated
- Network traffic analysis (Wireshark)
- Log analysis and threat detection
- Basic incident response workflows
- Vulnerability identification

## Lab Categories

### Network Analysis
Analyzing packet captures to identify suspicious traffic and anomalies.

### Log Analysis
Reviewing system and application logs to detect malicious activity.

### Web Exploitation
Identifying vulnerabilities in web applications (e.g., input validation issues).

### Incident Response
Simulating detection, analysis, and response to security incidents.

## Tools Used
- Wireshark
- Nmap
- Autopsy
- Linux CLI

## Goal
To build practical cybersecurity skills aligned with real-world security operations and training environments.
